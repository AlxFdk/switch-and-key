# Switch&Key

Навчальний вебпроєкт — інтернет-магазин механічних клавіатур, перемикачів та комплектуючих.
Виконано в межах дисципліни «Веб-орієнтована розробка програмного забезпечення».

## Опис проєкту

Switch&Key — спеціалізований магазин механічних клавіатур (формати 65–100%), перемикачів, кейкапів, плат та матеріалів для шумоізоляції. Ключові ідеї сайту:

- каталог з фільтрами за форм-фактором, типом кріплення та матеріалом корпусу;
- стенд аудіо-семплів тайпінгу, щоб послухати перемикач перед покупкою;
- кошик і форма оформлення замовлення без обов'язкової реєстрації.

Поточний етап — базова HTML-структура сайту (без CSS та JavaScript).
